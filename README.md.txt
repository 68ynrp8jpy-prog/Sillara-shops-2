# 🛒 Sillara Shop

Sri Lanka's best local shop directory – Find vegetables, fruits, groceries, milk, garages, phone shops, hardware and more near you.

## Features
- Shop registration with items & prices
- Search by district and village
- Rate shops (1-6 stars)
- AI Assistant (Sinhala/English)
- Google Maps directions
- Discount badge for offers

## How to Deploy on GitHub Pages
1. Upload all 4 files to a GitHub repository.
2. Go to **Settings → Pages**.
3. Set source to `main` branch, `/root` folder.
4. Access your app at `https://your-username.github.io/repo-name/`

## Files
- `index.html` – structure
- `style.css` – styles
- `script.js` – all logic
- `README.md` – this file
